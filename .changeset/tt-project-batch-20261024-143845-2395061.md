`tt-project`: the push queue reruns a failed check's failing tests once at the same head (flaky: the batch goes on, the coordinator is told once) and once on the tip alone (failing there: the tip is broken, not the change); the push queue never reruns a check that did not exit 1 or that pytest stopped early (-x, --maxfail, an interrupt), so a partial run cannot pass as flaky.
